# Bambu A1 assembly

[3D-модель и файлы для печати](https://hdzy.github.io/bambu-a1-assembly/)

Сборка из шести деталей по фотографиям и эскизу, без гравировки. На странице есть вращаемая модель, разнесённый вид, отдельные детали и размеры.

В `print/` находятся отдельные STL, два проекта 3MF для A1/PLA и инструкция. Основание печатается отдельно, остальные пять деталей вместе, с зазором минимум 16 мм. Толщина деталей 4 мм, диск Ø67,5 мм. В проектах принято сопло 0,4 мм и заполнение 30% Gyroid.

STL проверены на замкнутость, ориентацию и размеры. 3MF проверены по структуре и размещению; в Bambu Studio они ещё не нарезались.
